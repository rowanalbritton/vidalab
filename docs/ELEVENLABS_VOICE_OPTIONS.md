# ElevenLabs voice options for the meditation guides

Checked 2026-10-01 with the account's API key (read-only calls).

- **Plan:** Creator. 131,000 credits a month, 0 used. Resets 2026-11-01.
- **Cost:** a full render of 10 guides × 5 sessions is about 62,440 characters, and short previews of all 10 are about 1,590. With `eleven_multilingual_v2`, one character is one credit.
- **In the account now:** only ElevenLabs' 21 default ("premade") voices. Almost all are American. The only British ones are George, Alice, Daniel and Lily, and none has a French, Italian, Spanish or Indian accent.
- **Accents:** most guides need a voice from the **Voice Library**. To add one: Voices > Explore (Voice Library), search for its name, then "Add to My Voices". Library voices are free to add and can be used commercially on paid plans. The voice ID stays the same once it's added.
