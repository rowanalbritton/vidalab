# VIDA LAB website concept

This directory contains a new Netlify-ready VIDA LAB homepage concept created 2026-09-17 from the native app's design language and product contract.

The **current production website remains `site/`**, because `netlify.toml` publishes that directory. This prototype is intentionally separate so a design review does not unexpectedly replace the live site. Once approved, its strongest elements can be promoted into `site/` while preserving the existing Research Explorer, condition pages, app page, About page, newsletter forms, and legal routes.

Cross-platform decisions are documented in `docs/PLATFORM_SOURCE_OF_TRUTH.md`. Rork, Netlify, Supabase, RevenueCat, and iOS work should use that file as the shared product contract.
